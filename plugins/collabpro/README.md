# CollabPro plugin for Claude

Bundles the CollabPro connector with a skill that teaches Claude to search, draw and export CollabPro diagrams.

**Before using or submitting this bundle, replace `YOUR-COLLABPRO-HOST` in `.mcp.json`** with the public HTTPS host of the CollabPro instance people will connect to (the same fixed `/api/mcp` URL as the directory listing). The placeholder is intentional: this repository is self-hosted software and has no single canonical URL to ship.
